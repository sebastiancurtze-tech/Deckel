# Deckel

Punkte zählen für eure Spieleabende – mit euren Hausregeln.

Installierbare Web-App (PWA): Kubiki, Zehntausend, Kniffel, Schocken und Mäxchen, eigene Spiele im Baukasten, Statistik über alle Spieleabende. Läuft offline.

**Installieren:** Seite im Handy-Browser öffnen, dann
- iPhone (Safari): Teilen → „Zum Home-Bildschirm“
- Android (Chrome): Menü ⋮ → „App installieren“
